# 배포 안내 (Vercel)

직원 PC에서 접속할 수 있게 인터넷에 올리는 방법이에요. 코드는 이미 배포 가능한 상태예요(운영용 빌드 통과, 비밀키는 저장소에 없음).

## 1. Vercel 프로젝트 만들기
1. https://vercel.com 에 GitHub 계정(KMDDKKIM)으로 로그인
2. **Add New → Project** → `ondam-dashboard` 저장소 **Import**
3. Framework Preset: **Next.js** (자동), Root Directory: 그대로(저장소 맨 위), Production Branch: `master`

## 2. 환경 변수 (Environment Variables) — Production, Preview, Development 모두 체크
`.env.local` 파일에 있는 값을 그대로 붙여넣어요.

| 이름 | 꼭 필요 | 설명 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 예 | Supabase 프로젝트 주소 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 예 | 공개(anon) 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | 예 | **서비스 키 — 절대 다른 곳에 공유하지 말 것.** 없으면 빌드가 실패해요 |
| `ANTHROPIC_API_KEY` | 상담 녹음 차팅을 쓸 때만 | 원장님 전용 기능 |
| `REMOTE_CONSULT_INGEST_SECRET`, `REMOTE_CONSULT_RRN_KEY` | 비대면진료 자동 전송을 켤 때만 | 키는 잃어버리면 복구 불가라 따로 백업 |

## 3. Deploy 후 확인
1. 발급된 주소(예: `https://ondam-dashboard.vercel.app`)로 접속 → 로그인 화면이 나오면 정상
2. 원장님 계정(김동규)으로 로그인 → 오늘 화면, 일일결산, 접수기록부가 열리는지 확인
3. 직원 한 명이 `/signup`에서 가입 신청 → 원장님이 직원 승인 화면에서 승인 → 그 직원으로 로그인해 보기
4. 직원 계정에서 「상담 녹음 차팅」 메뉴가 안 보이는지 확인

## 4. 이후
- `master`에 push 하면 자동으로 다시 배포돼요.
- 환경 변수를 바꾸면 **Redeploy**를 눌러야 반영돼요.
- 저장소가 공개(Public) 상태예요. 환자 데이터는 저장소가 아니라 Supabase에만 있지만, 코드가 공개되는 것이 싫으면 GitHub 저장소 Settings → Danger Zone → **Change visibility → Private** 로 바꾸세요(Vercel 연결은 그대로 유지돼요).
- Vercel 무료(Hobby) 요금제는 상업적 사용이 약관상 제한돼요. 병원 운영 도구는 유료(Pro) 요금제가 안전해요.
